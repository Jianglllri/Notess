# 枝叶学习笔记使用指南

## 修改、编辑与保存

点击左侧笔记即可修改标题和正文。可以在所见即所得、Markdown 编辑、双栏预览和阅读模式之间切换。

编辑后自动保存在当前设备，顶部出现“已保存到本地”表示保存完成。重新打开应用仍能继续编辑。建议定期导出 ZIP 备份。

## 提交和更新 GitHub

1. 打开 GitHub 导入 / 发布。
2. 使用仓库 https://github.com/Jianglllri/Notess，分支 main。
3. 在软件内填写具有此仓库 Contents 读写权限的 Token，不要写入笔记或提交到仓库。
4. 首次发布填写路径，例如 notes/我的学习笔记.md。
5. 之后编辑笔记，点击更新笔记并提交到 GitHub，更新的是同一个文件，历史版本由 GitHub 保存。
6. 如果其他设备修改了远端文件，提交会停止。查看远端版本，把需要的内容合并到本地后再提交。

本地自动保存与 GitHub 提交是两个独立步骤，断网也能编辑和保存。

## 考试

使用二级标题 Q: 或 问题： 标记题目，后面写参考答案。点击随机考试，输入答案后提交才显示参考答案。
