# 枝叶学习笔记使用指南

## 卡片记录与编辑
首页快速记下想法，用 #标签 分类，点击卡片可继续编辑标题、正文和标签。支持所见即所得、Markdown、双栏预览。编辑自动保存在本机。

## 默认笔记库
默认连接 https://github.com/Jianglllri/Notess，分支 main。每次启动自动获取仓库笔记，也可点击刷新笔记库。

修改完成后点击“保存更新到 Notess”，已有笔记更新原文件，新笔记保存到 notes 目录。桌面版优先使用本机已有 GitHub 登录；没有登录时可在“导入 / 仓库设置”填写有 Contents 读写权限的 Token。Token 不要写入笔记。

本地与远端同时改动时会保留本地并提示冲突，请查看远端版本，合并需要保留的内容后再提交。离线可以继续编辑，建议定期导出 ZIP 备份。

## 导入与考试
支持 GitHub 仓库、目录、文件和 vscode.dev/github 链接。已导入的 Agent 面试题库位于 imports/agent-interview-300，保留原始目录和来源说明。

点击“随机考试”从题库抽题，自己输入答案，提交后才展示参考答案。支持面试题库格式，也支持使用二级标题 Q: 或 问题： 编写自己的问答。
