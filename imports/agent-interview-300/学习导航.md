## 建议学习顺序

1. **基础准备**：LLM 基础 → 提示工程，先掌握模型机制与提示设计。
2. **Agent 架构**：核心概念 → 单 Agent → 多 Agent，理解工具调用、规划与协作。
3. **工程落地**：RAG → 开发框架 → 系统集成 → 性能优化。
4. **可靠性与应用**：安全 → 治理与伦理 → 技术趋势 → 行业应用。
5. **面试复习**：结合真题，自述答案，再回到对应专题查漏补缺。
